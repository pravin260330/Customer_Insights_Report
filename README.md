# 🧠 Customer Insights and Reporting Dashboard (Power BI)

This project focuses on creating an interactive and insightful **Customer Insights Dashboard** using **Power BI**, built as part of a Data Analyst internship. The dashboard is designed to help stakeholders understand customer behavior, segmentations, engagement, and financial trends using visual KPIs.

## 📊 Objective

To analyze customer data and deliver meaningful insights through a well-designed Power BI dashboard, focusing on customer retention, engagement, product usage, and financial health.

---

## ✅ Key Features

- Professionally formatted dashboard with **5 key visuals**
- **Dropdown slicers** for CustomerID, Gender, Geography, and Card Type
- Slicer panel positioned for optimal UX (top/right/left)
- **Bookmarks** and **parameters** implemented for enhanced interactivity
- KPI-based layout aligned with business use cases

---

## 📌 KPIs and Use Cases

### 1. **Customer Retention and Churn**
- **KPI**: Churn Rate  
- **Purpose**: Tracks customer exits to monitor retention trends  
- **Use Case**: Helps identify high-churn periods and customer engagement gaps

### 2. **Customer Segmentation**
- **KPI**: Segments by Geography, Gender, Age, Tenure  
- **Purpose**: Understand customer distribution across demographics  
- **Use Case**: Target marketing strategies to specific customer groups

### 3. **Customer Engagement**
- **KPI**: Active Member Rate  
- **Purpose**: Shows how engaged customers are with services  
- **Use Case**: Higher engagement indicates higher revenue potential

### 4. **Credit Usage**
- **KPI**: Credit Card Usage Rate  
- **Purpose**: Tracks credit card adoption  
- **Use Case**: Supports cross-selling strategies

### 5. **Financial Health**
- **KPI**: Average Account Balance  
- **Purpose**: Highlights high-value customers  
- **Use Case**: Basis for premium services or offers
